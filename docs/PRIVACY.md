# Privacy

Runiverse 1.0.0 operates entirely offline.

It stores run dates, distances, durations, optional notes, personal rewards,
and game preferences in a local SQLite database in private Android storage.

Runiverse does not include user accounts, advertising, analytics, cloud
synchronization, GPS tracking, Health platform integrations, or a remote server.

Clearing app data or uninstalling Runiverse deletes its database. Version 1.0.0
does not yet provide an export or backup function.
