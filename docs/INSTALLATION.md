# Installing Runiverse on Android

## Requirements

- Android 7.0 or newer.
- Approximately 100 MB of free storage.

## Installation

1. Download `Runiverse-1.0.0.apk` from the repository.
2. Open the APK from the browser, file manager, messenger, or cloud application.
3. If Android blocks it, open **Settings > Install unknown apps** and allow the
   application used to open the APK.
4. Return to the APK and press **Install**.
5. Open **Runiverse** from the launcher.

Google Play Protect can display a warning because this APK is distributed
directly instead of through Google Play. Version 1.0.0 is signed for personal
sideloading.

## Updating and removing

An update must use the same application ID and signing key. Do not uninstall
before an update: uninstalling or clearing app data removes all locally stored
runs, rewards, and settings.
